The method

The rubric is the product.

1

Write it once, lock it

Weighted criteria are fixed on-chain before the first entry, so nobody can move the goalposts.

2

Validators read every entry

Each one opens the submitted link and scores it per criterion with written reasons.

3

Consensus pays out

When validators agree on the ranking, the contract releases the prize to the winner.

Every score. Every reason. On the record.
